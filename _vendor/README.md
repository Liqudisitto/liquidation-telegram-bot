# Встроенная зависимость

Папку `_vendor` нужно переносить в репозиторий **целиком**, рядом с `main.py`.
В FIX1 она позволяет проверять Workshop, даже если окружение BotHost не
переустановило пакеты из requirements.txt.

В `websocket/` находится неизменённый код библиотеки **websocket-client 1.9.0**,
лицензия Apache-2.0 — в `websocket/LICENSE`. Тесты библиотеки и консольная утилита
wsdump не включены. Проверены SHA-256 исходных файлов по RECORD установленного
пакета. Загрузка выполняется как `_vendor.websocket`; sys.path не меняется.

Источник: https://pypi.org/project/websocket-client/1.9.0/
Код: https://github.com/websocket-client/websocket-client

Бот использует эту копию первой. Если её нет, допустима установленная через pip
библиотека websocket-client **1.9.0**. TLS-проверка сертификатов остаётся включена.
Сам бот ничего не устанавливает из сети при запуске.
