# Проверки 1.4.2.6.9

**41 проверка бота — успешно**, лог `tests/BOT_1_4_2_6_9_RESULTS.txt`.
Проверены существующие действия с персонажами и новый раздел «Ликвидус»: работа при выключенной игре, оба списка доступа, одноразовые подтверждения, отмена и истечение подтверждения, смена состояния/перезапуск контейнера, запрет принудительного kill, точные команды и REST-маршруты, отсутствие повтора POST при тайм-ауте, редактирование того же сообщения и возврат в раздел. Проверяются чтение строки обстоятельств смерти, русские части тела и запрет ложной отметки смерти живого персонажа.

```bash
python3 -m unittest discover -s tests -v
```

Тесты выполнялись на Python 3.12.14; синтаксис всех Python-файлов также проверен парсером в режиме Python 3.11. Рабочее окружение BotHost/Docker настроено на **Python 3.11**, внешних зависимостей нет.

Telegram, HTTPS и панель в тестах подменены: ни одна команда не отправлялась на живой сервер. Принятие команды API не выдаётся за подтверждение сохранения мира/завершённого запуска.

Игровой мод прошёл отдельно **126 проверок Lua 5.1**, обмен Lua → Python и сценарии открытого Java Kahlua. Это проверка кода и совместимости форматов, а не запуск движка PZ. Установка на EGNetwork и живой мультиплеер остаются проверкой после публикации.
