# Проверки бота 1.4.1

Выполнено **27 проверок**, лог `tests/BOT_1_4_1_RESULTS.txt`.

Проверены доступ только разрешённых администраторов в личном чате, `/myid` до настройки доступа, привязка подтверждения к автору/персонажу/сессии/загрузке сервера, одноразовые кнопки, блокировка старых снимков, изменение XP и запрет переноса навыков чужого аккаунта. Тайм-аут записи команды не вызывает повторный POST.

В 1.4.1 добавлены проверки возврата к карточке того же персонажа после всех действий, редактирования одного сообщения, страниц Unicode-отчёта, выбора верхней отсутствующей части руки, сохранения квитанции после ошибки обновления карточки/Telegram, отмены устаревшего подтверждения и раздельных сообщений разных администраторов. Проверяется настоящий обработчик HTTP 400 Telegram с имитацией ответа сервиса.

```bash
python3 -m unittest discover -s tests -v
```

Тесты подменяют Telegram и панель игрового сервера. Они не подключаются к аккаунтам или живому серверу. Выполнены здесь на Python 3.12; синтаксис всех Python-файлов проверен для 3.11. Бот рассчитан на стандартную библиотеку Python 3.11, как указано в `bothost.json` и `Dockerfile`; внешних пакетов не требуется.

Игровая часть имеет отдельные **118 проверок**, в том числе 10 сценариев восстановления на настоящем коде данных/кэша присланного Only Cure с имитацией объектов движка. Дополнительно выполнены сценарий Java Kahlua и обмен Lua ↔ Python. Отчёт находится в `TESTING.md` архива игрового мода. Реальный мультиплеерный запуск здесь не выполнялся.

Установка и проверка на сервере: `UPDATE_1_4_1_RU.md`.
